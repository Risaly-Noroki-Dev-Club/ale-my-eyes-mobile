# Fluent System Icons

The SVG files without the `figma-` prefix are selected assets from Microsoft's
[Fluent System Icons](https://github.com/microsoft/fluentui-system-icons).
They are distributed under the MIT License in
`LICENSE.fluent-system-icons.txt`.

The `figma-*.svg` files are exact vector exports from the user-supplied Figma
file `KxBVpPWMx63te4qE45p205`, scan frame `2:144` (2026-09-10).
They retain the exported viewBox and intrinsic aspect ratio. Navigation uses a
24px containing box with `image-fit: contain`; the accessibility mark, success
check and device check retain their individual 18x20, 18.5x13.5 and 44x44 sizes.
The Figma assets are separate from the Fluent icon collection above.
